# Uivc AI Club Website 

Welcome to the official repository for the **UVic AI Club** website. This repository contains all the code, content, and assets used to build and maintain the club site:

https://uvicai.ca/

To run the website locally, follow the steps below.

### 1. Clone the Repository

```bash
git clone https://github.com/uvicaiclub/clubwebsite.git
cd clubwebsite
```
### 2. Install Dependancies
You'll need [Ruby](https://rubyinstaller.org/) installed on your system. (Ruby 3.3.8 worked for me)

Once Ruby is installed, install Bundler:
```bash
gem install bundler
```
Then, still inside the clubwebsite folder, install the project dependencies. This may take some time:
```bash
bundle install
```

### 3. Run the Website Locally for Editing
Run the following command to build and serve the site locally using Jekyll:
```bash
bundle exec jekyll serve
```
Visit http://localhost:4000 in your browser to preview the site.
